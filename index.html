🔧 One-Time Setup (5 minutes)
Do this once — both devices then share the same Sheet URL
  1. Create a new Google Sheet

    Go to sheets.google.com and create a blank spreadsheet. Name it e.g. "Stokes Inspections KPI".

  2. Open the Apps Script editor

    In your Google Sheet click Extensions → Apps Script. Delete all the default code in the editor.

  3. Paste this script and Save
    const SHEET_NAME = 'Inspections'; function doGet(e) { const ss = SpreadsheetApp.getActiveSpreadsheet(); let sheet = ss.getSheetByName(SHEET_NAME); if (!sheet) return respond({status:'ok', data:[]}); const data = sheet.getDataRange().getValues(); if (data.length < 2) return respond({status:'ok', data:[]}); const headers = data[0]; const rows = data.slice(1).map(row => { const obj = {}; headers.forEach((h,i) => { obj[h] = row[i]; }); return obj; }); return respond({status:'ok', data: rows}); } function doPost(e) { try { const payload = JSON.parse(e.postData.contents); const ss = SpreadsheetApp.getActiveSpreadsheet(); let sheet = ss.getSheetByName(SHEET_NAME) || ss.insertSheet(SHEET_NAME); if (payload.action === 'save') { const headers = ['id','date','inspector','caseNumber','type', 'requestDate','completionDate','result','isReinspection','address']; sheet.clearContents(); sheet.appendRow(headers); payload.data.forEach(row => { sheet.appendRow(headers.map(h => row[h] !== undefined ? String(row[h]) : '')); }); return respond({status:'ok', saved: payload.data.length}); } return respond({status:'error', message:'Unknown action'}); } catch(err) { return respond({status:'error', message: err.toString()}); } } function respond(obj) { return ContentService.createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); }
  4. Deploy as a Web App

    Click Deploy → New deployment. Set type: Web app, Execute as: Me, Who has access: Anyone. Click Deploy and copy the URL shown.

  5. Paste the URL here and connect

    Use the exact same URL on both devices — they will share all data automatically.

📲 Install as App (Free — No App Store Needed)
This tracker is a Progressive Web App (PWA). Install it to your home screen and it works exactly like a native app — offline, full screen, no browser bar.
🤖 Android (Chrome)
  1. Open this file in Chrome on your Android device (or have someone text/email you the link if it's hosted)
  2. Tap the three-dot menu ⋮ in the top-right corner
  3. Tap "Add to Home screen" or "Install app"
  4. Tap Install in the popup — done! ✅
💡 If you see the "Install this app" banner at the top of this page, just tap that instead — it's even faster.
🍎 iPhone & iPad (Safari)
  1. Open this file in Safari — it must be Safari, not Chrome, for install to work on iOS
  2. Tap the Share button ⎙ at the bottom of the screen (or top-right on iPad)
  3. Scroll down in the share sheet and tap "Add to Home Screen"
  4. Edit the name if you like, then tap Add — done! ✅
💡 On iOS the app icon will use the clipboard icon you set. The app opens full-screen with the navy header, just like a native app.
🌐 Want it on both your PC and phone?

Host the HTML file on GitHub Pages (free, takes 5 minutes) and you get a permanent HTTPS URL. Then:

  • Install it as an app on your phone from that URL
  • Bookmark it on your PC
  • The service worker caches it so it works 100% offline on all devices
  • Connect Google Sheets sync so all devices share one dataset
ℹ️ How sync works

• Every add, import, or delete automatically saves to your Google Sheet.

• Opening the app on any device loads the latest data from the Sheet first.

• If offline, the app uses locally cached data and syncs when reconnected.

• Paste the same URL on your PC and tablet — that is the only step needed on the second device.
